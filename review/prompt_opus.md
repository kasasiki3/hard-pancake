# 依頼: BLDCモータードライバ「固いパンケーキ」の回路・基板の査読

出力・実況・findingsまで全部日本語で書け。冒頭に自分のモデルIDを自己申告せよ。
成果物は必ず `review/findings_opus.md` にファイルとして直接書け（opusは依頼末尾で指定）。他のファイルは一切変更するな。
書き終えたら最終行に `=== CODEX DONE (exit 0) ===` と書け。
日本語ファイルはPowerShellの Get-Content / Set-Content / Out-File を使わずエディタツールで読み書きせよ。シェルが要るなら `bash -lc "cat file"`。

## 対象（作業ディレクトリ = プロジェクトルート）

- `readme.md` 仕様・決定事項・ファームの前提・未確認リスト（**まずこれを全部読む。決定済み事項は再提案しない。決定が電気的に間違っている場合だけ指摘する**）
- `設計チェック.md` 前回の設計チェック（反映済み）
- `BOM.md`
- `review/netlist.txt` 全部品・全ピン→ネット（KiCad 10から今日出力。これが正）
- `review/placement.txt` 部品座標・回転・面、配線幅とビアの集計、ゾーン
- `review/drc.rpt` DRC結果（未配線0、回路図との不一致0、シルク関係の警告のみ）
- `review/img/F.Cu.png` `In1.Cu.png` `In2.Cu.png` `B.Cu.png` 各銅箔層（81×68mm、4層1oz）、`F.Fab.png` 部品配置
- `review/img/sch_1..4.png` 回路図（ルート／電源／制御／パワー段）
- `datasheet/` DRV8323R、NTMFS5C628NL（C145537）、CA-IS2062A、118EC447、STM32（中身はG474版）
- `sim/` LTspiceのハーフブリッジ・降圧の近似シミュレーション、`tools/check_pcb.py` `tools/amp_check.py` 基板の計算

構成の要点: 6S LiPo（最大25.2V）、ピーク30A／平均5A、STM32G431CBT6、DRV8323RH（ハードウェアモード、6x PWM、内蔵アンプ40倍、0.5mΩローサイドシャント×3、VDS監視0.13V）、NTMFS5C628NL×6、絶縁CAN-FD（CA-IS2062A）、MT6701エンコーダ×2ポート、3.3VはRT9013（DRV内蔵5V降圧から）、JLCPCBでPCBA製造。

## 見る観点（3つ全部）

1. **回路の誤り**: ネットリストをピン単位で読み、データシートと突き合わせる。ピンの取り違え、電源・GNDの未接続、極性、定数（分圧・RC・ゲイン・しきい値）、耐圧、STM32のピン機能（AF・ADC・COMP・TIM1）、起動時・リセット中・電源片側だけの状態、絶縁の跨ぎ。
2. **BLDCモータードライバ設計の定石への違反**: TI SLVA959（レイアウト）、SLVAF66（高出力設計）、SLVAFT0（バルク容量）、DRV8323Rデータシートのレイアウト章の項目を基準に、回路と基板の両方を見る。例: 高電流ループ面積、バルク/セラミックの位置、ゲート線とリターンの組、シャントのケルビン、SHx/SPxの引き回し、サーマル、GNDの分割、検出線とスイッチノードの距離、電流容量（銅幅・ビア数）、CAN絶縁島のクリアランス。
3. **シミュレーションで確かめるべき点・既存シミュの妥当性**: `sim/` の条件・モデル化の抜けや誤り、追加で回すべき条件（具体的な値で）。

加えて、**JLCPCBで製造（PCB＋PCBA）するうえでの障害**（DFM、部品の入手、フットプリントの誤り、LCSC番号の欠落、極性・回転）も挙げよ。

## 書き方

findingsは重大度順。各項目に:
- 重大度: 致命（作ると動かない／壊れる）／重大（性能・信頼性を大きく損なう）／軽微／確認要
- 場所: Ref.ピン、ネット名、座標(mm)、ファイル名
- 根拠: データシートのページ・表番号、計算式と数値。推測は「推測」と明記
- 直し方: 具体的に（部品値、接続、配置）

一般論の羅列は不要。この設計の具体的な問題だけを書け。確認できなかったものは「未確認」とし、「問題なし」に読み替えるな。問題が見つからない観点は「問題なし（確認した内容）」と1行書け。
