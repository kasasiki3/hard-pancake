# 固いパンケーキモータードライバ

5010クラスのBLDCをFOCで駆動し、ついでにRZ-735等のブラシ付きDCモーターも駆動する、CAN-FD接続の1ch 3相モータードライバ。
当面はブラシ付き（735）で使い、将来BLDC（5010）へ流用する。基板は同一、ファームの切り替えで対応する。

部品の候補と選定状況は [BOM.md](BOM.md)。

## 仕様（目標）

| 項目 | 仕様 | 備考 |
|---|---|---|
| 対応モーター | 3相BLDC（FOC）／ブラシ付きDC | DCは3相のうち2相をHブリッジとして使う |
| 電源電圧 | 12V〜24V公称（3S〜6S LiPo） | 動作範囲 10V〜25.2V（6S満充電）、絶対最大 30V（回生・サージ込みの目標） |
| 連続電流 | 40A（相電流RMS、BLDC時）／40A（DC時） | 冷却条件は未定。ヒートシンク・風冷前提で評価する |
| ピーク電流 | 未定（60A程度を想定） | 過電流遮断の閾値と兼ねて決める |
| 通信 | CAN-FD（公称1Mbps／データ最大5Mbps想定） | 120Ω終端をはんだジャンパで切替。デイジーチェーン用にコネクタ2個 |
| マイコン | STM32G431系（UFQFPN-32、STM32G431KBU6想定） | Cortex-M4F 170MHz、FDCAN、OPAMP、COMP、DAC、TIM1で6ch相補PWM |
| 電流検出 | 3相ローサイドシャント＋内蔵OPAMP（PGA） | FOC用。DC時は2相分を使う |
| 過電流保護 | 内蔵COMP＋内蔵DAC → TIM1ブレーク入力でハードウェア遮断 | ファームを介さず数µsで全相OFF。735の突入・ロック電流対策を兼ねる |
| 電圧検出 | VBUS分圧をADCへ | 過電圧時は回生を止める／ブレーキ抵抗は載せない（未定） |
| 温度検出 | FET近傍のNTCをADCへ | モーター温度用の入力は余りピン次第 |
| 位置センサ | 外部磁気エンコーダ（SPI／ABZ）用コネクタ | 5010用。センサレスFOCも選択肢として残す。DC時は不使用 |
| デバッグ | SWD（Tag-Connect or 1.27mmピンヘッダ） | ブートローダ経由のCAN書き込みも将来検討 |
| 製造 | PCBA（片面実装を目標） | 4層・外層厚銅を想定。供給安定と単価を部品選定の第一条件にする |

## 設計方針

- 3相ハーフブリッジ×3を常に実装し、ブラシ付きDCは2相（例: U-V）でHブリッジ駆動する。残り1相は未使用。
- 電流検出はマイコン内蔵OPAMPを使い、外付けの電流センスアンプを省く。G431の32ピン版でOPAMP3個の入力ピンとTIM1のPWMピンが両立するかはCubeMXで要確認。
- 過電流はソフトに頼らずCOMP→TIM1 BKINで切る。735は停動時に大電流が流れるので、DC運用でもこれが主な保護になる。
- 部品はPCBA業者の常備品（JLCPCBならBasic/Preferred）を優先し、無い場合は在庫の多い拡張品から選ぶ。単一ソース品（代替が利かないもの）は避けるか、ピン互換の代替を BOM.md に必ず併記する。

## 未決事項

- **MOSFETの耐圧（40V or 60V）**: 6S満充電25.2Vに対し40V品は余裕1.6倍。TVSのクランプ電圧（SMBJ26A級で40V強）がFETの耐圧を超えるので、40V品なら回生対策をバルクコンデンサと電圧監視で取る必要がある。60V品はRds(on)と単価が悪化する。
- **ゲートドライバの形態**: 3相統合品（電流アンプ・保護内蔵）か、安価な3相プリドライバか。内蔵OPAMPを使う前提なら後者で足りる。
- **ゲート駆動電源**: 入力10V付近ではゲート電圧10Vを確保できない。プリドライバの低電圧ロックアウトと入力下限の関係を決める。
- **PCBA業者**（JLCPCB想定、未確定）、基板サイズ、取付穴ピッチ。
- **電源・モーターの接続形態**（XT30/XT60/MR30か、はんだパッドか）。
- **CANのコネクタとプロトコル**（JST GH 4P想定、メッセージ定義は別途）。
- **エンコーダの載せ方**（基板上に載せてモーター背面に付けるか、外付けか）。
