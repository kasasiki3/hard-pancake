# 固いパンケーキモータードライバ

5010クラスのBLDCをFOCで駆動し、ついでにRZ-735等のブラシ付きDCモーターも駆動する、CAN-FD接続の1ch 3相モータードライバ。
当面はブラシ付き（735）で使い、将来BLDC（5010）へ流用する。基板は同一、ファームの切り替えで対応する。

決定済みの部品は [BOM.md](BOM.md)。

## 仕様

| 項目 | 仕様 | 備考 |
|---|---|---|
| 対応モーター | 3相BLDC（FOC）／ブラシ付きDC | DCは3相のうち2相をHブリッジとして使う |
| 電源電圧 | 12V〜24V公称（3S〜6S LiPo） | 動作範囲 10V〜25.2V。入力TVS（SMBJ30A、クランプ48.4V）以降の部品は全て耐圧50V以上 |
| 電流 | ピーク40A／平均5A程度（ロボコン足回り想定） | 過電流はハードウェアで遮断 |
| 通信 | CAN-FD 1ch（TCAN1044V） | コネクタはRJ45×2（デイジーチェーン）。終端はスプリット終端をはんだジャンパで切替 |
| マイコン | STM32G431CBT6（LQFP-48） | Cortex-M4F 170MHz、FDCAN、OPAMP×3、COMP、DAC。HSEは8MHz水晶（CANのクロック精度のため） |
| 電流検出 | 3相ローサイドシャント0.5mΩ＋内蔵OPAMP（PGA） | 抵抗でオフセットを与えて双方向を測る。DC時は2相分を使う |
| 過電流保護 | 内蔵COMP＋内蔵DAC → TIM1ブレーク入力でハードウェア遮断 | サイクルバイサイクルで電流を制限。735のストール対策を兼ねる |
| 電圧検出 | VBUS分圧（100k/5.6k、約62Vフルスケール）をADCへ | 過電圧でショートブレーキ |
| 温度検出 | FET近傍のNTC（10kΩ）をADCへ | |
| エンコーダ | 2ポート。ポート1: ABZ＋SPI（アブソリュート用）、ポート2: ABZ | 想定はMT6701等。VCCは3.3V（SPI入力のHレベルをMCUの3.3Vで満たすため）。信号線は直列抵抗＋ESD保護 |
| 電源系統 | VBUS → 12V（TPS7A4101、ゲート駆動）／VBUS → 5V（LMR51625、CAN）→ 3.3V（RT9013、MCU・エンコーダ） | |
| デバッグ | SWD | コネクタは後で選定 |
| 製造 | PCBA（JLCPCB想定） | 供給安定と単価を部品選定の第一条件にする |

## エンコーダ端子の信号

- ポート1: VCC、GND、A、B、Z、CS、SCK、MISO、MOSI
- ポート2: VCC、GND、A、B、Z
- ABZはタイマのエンコーダモードに入れる（2ポート分で2タイマ）。SPIはポート1のみ。

## 設計方針

- 3相ハーフブリッジ×3を常に実装し、ブラシ付きDCは2相（例: U-V）でHブリッジ駆動する。残り1相は未使用。
- 電流検出はマイコン内蔵OPAMPを使い、外付けの電流センスアンプを省く。
- 過電流はソフトに頼らずCOMP→TIM1 BKINで切る。
- 部品はJLCの在庫が多く単価の安いものを選ぶ。

## 決定の経緯

- 回路図はシート内を配線でつなぎ、ネットラベルを使わない形に作り直した（2026-11-23）。シートは電源・制御（MCU・CAN・エンコーダ）・パワー段の3枚で、シート間の信号は階層ラベルとルートシートの配線でつなぐ。配線が交差しにくいように、GPIOの割り当てを変更した（エンコーダ1 CS→PC14、エンコーダ2 Z→PA5、LED1→PB10、LED2→PA2）。TCAN1044VのSTBはGNDに固定した（常時ノーマルモード）。
- MCUはUFQFPN-32（KBU6）から LQFP-48（CBT6）に変更（2026-11-23）。エンコーダ2ポート＋SPIを追加するとPWM・OPAMP・FDCAN・SWDと合わせてGPIOが足りないため。CBT6の方が単価も安く在庫も多い（$3.09／4,672個 vs $7.23／350個）。
- FETは60V品（NTMFS5C628NL、ODrive v3.4 48V版で採用実績）に仮決定（2026-11-22）。
- ゲートドライバはDRV8300DRGER、ゲート駆動電源はTPS7A4101で12V（2026-11-22）。DRV8300のGVDDは最大20Vで6Sを直接入れられないため。
